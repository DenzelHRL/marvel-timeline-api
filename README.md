# Marvel Timeline API

API para explorar uma seleção de filmes e séries da Marvel por meio de uma linha do tempo. A proposta é relacionar obras, personagens e acontecimentos importantes, com informações que possam ser consultadas sem spoilers e detalhes revelados separadamente.

Este repositório contém o **backend do Trabalho P1** de Programação Web. A interface visual será uma etapa posterior.

## Situação atual

- Repositório e projeto NestJS criados.
- Aplicação inicial testada em `http://localhost:3000`.
- Modelagem, módulos e divisão das tarefas: a definir com o grupo.
- A rota inicial `Hello World!` é apenas um teste da estrutura.

## Como executar

Requisitos: Node.js 24.15+ e npm.

```bash
cd backend
npm ci
npm run start:dev
```

A API inicial ficará disponível em `http://localhost:3000`.
